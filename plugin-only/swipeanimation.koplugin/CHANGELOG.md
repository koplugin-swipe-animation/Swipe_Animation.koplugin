# Changelog

## 2026-10-18 — v4.3 plugin-only single-menu distribution

- Packaged the upstream Swipe Animation v4.3 modules as a KOReader `.koplugin`.
- Added a runtime bridge so installation does not require replacing `frontend/ui/uimanager.lua`.
- Consolidated plugin controls, upstream animation settings, and status diagnostics under one `翻页动画设置` menu.
- Added Chinese distribution documentation, install/uninstall instructions, compatibility notes, and GPL-3.0 redistribution guidance.
- Kept the upstream animation core, settings module, and PDF module as source files in the package.

This is an unofficial experimental fork. The single-menu build has not been validated across all devices and KOReader versions.
